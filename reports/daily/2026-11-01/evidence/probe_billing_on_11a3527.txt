== 2. webhook signature edge cases (configured) ==
 no header                -> 400 {"error":"invalid signature"}
 garbage header           -> 400 {"error":"invalid signature"}
 wrong secret             -> 400 {"error":"invalid signature"}
 stale timestamp (1h)     -> 400 {"error":"invalid signature"}
 future timestamp (+1h)   -> 400 {"error":"invalid signature"}
 valid                    -> 200 {"status":"stored"}
 valid + junk v1          -> 200 {"status":"duplicate"}
 empty v1 only            -> 400 {"error":"invalid signature"}
 t missing                -> 400 {"error":"invalid signature"}
 body tampered            -> 400 {"error":"invalid signature"}
 replay of the valid event -> 200 {"status":"duplicate"}
 webhook secret unset but key set; signed with empty secret -> 503
